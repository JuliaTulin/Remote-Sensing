# Remote Sensing Projects

A collection of academic projects focused on satellite imagery processing, remote sensing and geospatial analysis.

## InSAR Ground Deformation Analysis – Kerman, Iran

**Tools:** ESA SNAP, Sentinel-1 SAR, Google Earth

### Project Overview

This project focused on analysing ground deformation following the December 2017 earthquake near Kerman, Iran, using Sentinel-1 SAR imagery and interferometric processing techniques.

### Methodology

The analysis was performed using ESA SNAP and included:

- Sentinel-1 SAR imagery acquisition and coregistration
- Interferogram generation and coherence estimation
- TOPS Deburst and interferogram filtering
- Phase unwrapping
- Conversion of unwrapped phase to ground displacement
- Terrain correction and coherence masking
- Export and visualization of results in Google Earth

### Results

The analysis identified ground deformation patterns associated with the earthquake. The results were visualized using interferograms and displacement maps.
